# Fix typos

Find typos in this repository.
Consider only files which are not git-ignored.
For typos which can be fixed without breaking anything (for example in documentation, doc-comments, strings, private functions, private class variables, local variables): Fix them.
For typos which cannot be fixed safely (for example in public APIs, names of public classes or functions): Report them for manual review.
